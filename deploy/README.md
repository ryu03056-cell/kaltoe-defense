# 칼퇴 디펜스

진상 클라이언트·상사·업무를 막고 칼퇴하는 직장인 랜덤 디펜스 게임 (프로토타입).

- 플레이: https://ryu03056-cell.github.io/kaltoe-defense/
- `index.html` — 최신 버전 (v2: 캐릭터 디자인, 대표 등급, 인사발령)
- `characters.js` — 직업·직급별 캐릭터 그리기
- `v1.html` — 첫 프로토타입

## 규칙
- 채용: 랜덤 직업·직급 직원 입사
- 같은 직원 3명 → 합성 (인턴·대리는 직업 랜덤 "이직", 과장부터 직업 유지 "승진")
- 인턴 → 대리 → 과장 → 부장 → 대표 (같은 직업 부장 3명 = OO 대표)
- 발령: 골드로 직원 직업 변경
- 쌓인 업무 100건 = 야근 확정, 10웨이브마다 상사 보스

밸런스 수치는 `index.html` 상단 `CFG`에서 조정.
